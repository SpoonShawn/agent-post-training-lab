# 实验收尾：已完成什么、能讲什么、不能讲什么

状态：2026-09-16，本轮预定范围已完成模型运行与结果审计，不需继续GPU。范围是合成BugOps环境、版本化评估、LoRA pilot、泛化诊断、报告呈现消融；不是所有最初设想的算法都做完。阶段001–031及原始失败永久保留。

这些数据服务不同阶段、部分是相关变体，不能直接相加后宣传成若干独立测试场景。报告LoRA并未集成进完整Agent，不能把报告成绩替换Agent任务率。

## 最终可复核结论

确认集48上下文×3布局：Base21/144，fixed56/144，mixed83/144。mixed比fixed高18.75个百分点，改善34条、退化7条；收益主要来自表格22/48→43/48，记录格式仅13/48→16/48。单seed描述性结果，不宣称统计显著。

两臂各192例、1epoch/24步、15960监督tokens，输入总tokens358554与359504，约0.265%差异；不称严格等算力。所有864条为合法JSON，仍有524条完整报告失败。mixed的记录组决策48/48但完整报告16/48，剩余主要是验证失败计数错误。模型“格式正确”“决策正确”“完整报告正确”是不同层次。

## 学习与面试叙述

可以按实际顺序讲：先搭建可重放工具环境和基线，发现exact-match误判合理路径，版本化修复评分；再做分组隔离LoRA，对模板内满分保持警惕；用成对压力测试发现事件时序和权限处理缺陷；最后固定数据、监督和步数，仅改变呈现方式进行对照，测到有收益但存在退化，保留负结果并停止追分。

适合简历的事实素材（应按自己实际理解和参与程度重写）：

- 构建中文合成BugOps工具使用实验，支持状态重放、故障注入和执行/证据/答案分层评估，版本化保留协议修订与失败案例。
- 使用Qwen3-4B进行LoRA实验，并通过按事件结构分组隔离及配对压力测试分析模板依赖、证据遗漏和权限判断问题。
- 在同192训练样本、24优化步的报告任务对照中，混合呈现训练使确认集完整报告正确率由38.89%提升至57.64%；同步记录7条配对退化，限定为单seed合成任务结果。

不要写：完整Agent真实业务准确率57.64%；训练数万条；完成DPO/GRPO；解决过拟合；生产部署；真实Android自动化验证；全部独立人工评审。上述说法没有本仓库证据。

## 未解决的问题与后续边界

历史计数与权限分类仍会错；单seed、小结构组、共享工具原语，不能推断真实业务泛化。独立人工审查不足，旧控制实验还有1条Base未决。未来可以做更多seed、工具事实聚合器、真实环境迁移和Agent集成，但应另立实验，不把未完成工作混入本轮结论。

本次收尾不要求把所有失败都修到正确。完成标准是问题、对照、结果、失败、限制和复现证据形成闭环，而不是追求满分。
