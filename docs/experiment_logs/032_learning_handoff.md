## 问题、原因与解决方案

1. 实验阶段多，容易把事务Agent成绩与单轮报告成绩混淆。明确两类任务、指标分母与数据规模，不相加为独立业务场景。
2. AI解释可能把错误机制说得过实。区分“计数与证据不符”的可确认事实和“内部重复数了哪一步”的未知机制；不把模板依赖当逐条已证因果。
3. 容易把模板内满分、低loss或合法JSON等同于泛化。通过真实退化案例和分类48/48但完整报告16/48解释分层指标。
4. 继续任务不意味着不断训练。此次按已同意的收尾方向继续学习交接，不新增GPU开销。未做DPO/GRPO、独立审查不足和旧未决项仍公开保留。
